## How the path works

The path has 19 weeks (0 to 18) in four phases. Each week adds one capability to a single project, an uptime monitor with a status page. Plan on 5 to 8 hours a week.

## How to use this site

- Follow the weeks in order. Each one ends with a "Done when" checklist.
- Open any topic track at any time. Each week lists the tracks to read alongside it.
