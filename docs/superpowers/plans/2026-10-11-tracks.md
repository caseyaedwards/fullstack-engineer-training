# Topic Tracks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 25 track stub pages with finished reference pages, each with diagrams, a tested Go or TypeScript example, and links into the weeks that use it.

**Architecture:** Each track page keeps the seven stub sections. Code shown on a page comes from `examples/go/tracks/<dir>/` or `examples/web/src/tracks/<slug>/` through `<CodeFrom>`, and CI runs those tests. Two new components, `<WeekLink>` and `<TrackLink>`, build base-aware links in prose; a build test checks every written page against the layout and checks that each link and anchor exists in `dist/`.

**Tech Stack:** Astro Starlight 0.42, MDX, D2 0.7.1 through `<Diagram>`, Go 1.24, TypeScript with Vitest, node:test build tests.

**Spec:** `docs/superpowers/specs/2026-10-10-fullstack-path-design.md`, section Topic Tracks. Approved track list and layout: project memory `topic-tracks`.

## Global Constraints

- Prose follows `docs/style-guide.md`. `node --test tests/build/prose.test.mjs` passes. No hedges, no contractions, Title Case headings, no backticks in headings, no parentheses except acronym expansions, spell out one to ten.
- Spell out every acronym on first use on the page, except the never-spell-out list in the style guide. Explain every term on first use: the reader knows TypeScript, React and testing, and is new to Go, Linux, networking and infrastructure.
- Each track page keeps its frontmatter `title` and `track`, adds a one-sentence `description`, and keeps these `##` sections in this order: What It Is, Diagrams, Example, In the Uptime Monitor, Common Mistakes, Going Deeper, Further Reading. `###` subsections are free.
- `<UsedInWeeks />` stays directly under the imports.
- At least two `<Diagram>` per page, at least one with `steps`. Diagram ids are unique on the page. Shapes a step highlights get short keys with no whitespace plus a label: `lb: load balancer`.
- At least one `<CodeFrom>` per page, from `go/tracks/<dir>/…` or `web/src/tracks/<slug>/…`. Go package directories drop hyphens: `operating-systems` becomes `operatingsystems`.
- Example tests run offline and pass under `go test -race` and `npm test` in `examples/web`. A test that needs a tool or service CI has fails when `CI=true` and the tool is missing, and skips otherwise, as the Week 17 and 18 tests do.
- In the Uptime Monitor links every week that lists the track in its frontmatter, with `<WeekLink n={N} anchor="…">`, pointing at the section of that week where the topic appears.
- Further Reading holds at least three external `https://` links to primary sources: official docs, RFCs, the Go blog, well-known books. Fetch each URL before you use it; drop any that does not answer 200.
- Example values come from the style guide: `192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`, `2001:db8::/32`, `example.com`.
- Weeks 0 to 5 are AI stage one, 6 to 12 stage two, 13 to 18 stage three. The AI-Assisted Development track owns the full explanation.
- No new npm dependencies. Go may use any module already in `examples/go/go.mod`, including the indirect `golang.org/x/net`.

## Review Focus

1. A link to a week anchor that does not exist: Starlight builds the page, and the reader lands at the top of the week. The `tracks.test.mjs` dist check fails on it.
2. A page that is half stub, half written: the layout test treats any page without the stub sentence as written and checks all sections.
3. Example tests that depend on the network or wall-clock timing: the timeout tests use generous bounds, 2 s for a 100 ms timeout, and only `127.0.0.1`.
4. The prose lint inside component children and diagram captions: the lint checks `caption` and `title` props, which is where hedges slip in.
5. Code on the page that drifts from the tests: every code block that a reader copies comes from `<CodeFrom>`, and short illustrative blocks in other languages stay under ten lines.
